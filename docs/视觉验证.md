# GLM-4.6V 第一轮视觉验证

> 更新：旧版登记路障的停步等待演示已被[局部感知导航](局部感知导航.md)替代。下面的停步测试和真实 API 结果保留为历史记录；当前绕行不依赖 VLM，不能将距离感知的成果归因于视觉模型。

手动视觉检查用于截图理解和动作前后比较；开启“视觉辅助动作决策”后，新鲜的人物视角观察会进入 Agent 的决策上下文。视觉始终不能替代物理成功判定。

## 视觉辅助动作决策

启动 brain_server.py 和 body_3d.py，在连接大脑前勾选“启用视觉辅助动作决策”（默认关闭，连接后锁定开关）。无语音识别模型时可使用 python brain_server.py --no-asr。

闭环顺序：场景开始或工作人员发言结束 → 人物视角观察 → Agent 结合视觉、身体状态和对话选择动作 → 现有控制器执行 → 行走到达或动作失败 → 再观察 → 下一轮决策。

- 所有机器人/柜员发言、场景开始、动作失败，以及行走完成事件会触发一次观察；不是每帧或每个物理步调用。手动文本输入也经过同一链路。
- 决策使用人物视角，不使用旁观全景。没有看到咨询台不代表咨询台不存在，允许按已有地图和工作人员指引前进。
- 每次事件带可选 vision：captured_at、command_id、view、phase、observation。服务器核对最新命令和时间，下一轮消费后清空；没有新观察时不沿用旧截图作为当前证据。
- 自动观察最多等待 20 秒墙钟时间。超时、请求失败、并发占用或缺少截图能力时，不附带视觉，继续原有事件流程。后端请求可能仍在完成，期间新调用会返回忙。
- 超过 30 仿真秒、人物位移超过 0.15 米、根部或颈部转动超过 0.15 弧度、场景重载、连接断开或命令变化时，丢弃结果。倍速可能使视觉结果更快过期。
- 新一轮可选择继续、可用的转头动作、其他已有地点或求助；不会凭视觉编造目标坐标。没有新增自动转身扫描、动态障碍绕行或视觉伺服控制器。当前固定左右转头仍有能力限制。
- 决策前后观察本身不触发第二次独立决策。行走途中另有下述障碍检查，可请求停步；收到物理失败不能被视觉描述覆盖为成功。

验证覆盖：模拟视觉服务的浏览器流程中，行走完成事件携带人物视角与匹配 ID，柜员发言携带决策前观察；视觉 502 回退原流程；断开后的迟到结果不再发送事件。Python 测试验证过期/错 ID/旁观视角被过滤，以及失败视觉进入真实会话和决策代码后仍受重复失败保护。模型回复与身体反馈使用模拟数据，尚未完成真实双模型驱动的整条银行路线测试。

## 使用

1. 在根目录安装依赖：`pip install -r requirements.txt`、`npm.cmd ci`。
2. .env 已有 GLM_API_KEY 时直接复用；视觉模型默认 glm-4.6v。可通过 VLM_API_KEY、VLM_BASE_URL、VLM_MODEL、VLM_TIMEOUT 单独配置，修改后重启服务。
3. 启动 `python body_3d.py`，打开 http://127.0.0.1:8080。不需要启动 brain_server.py。
4. 展开右侧“视觉检查 · GLM-4.6V”，选择人物视角或当前旁观视角，点击“识别当前画面”。
5. 对比动作时，先“保存动作前截图”，用“本地动作检查”执行动作，然后点击“对比动作前后”。两张截图之间保持视角一致；挥手会回正，需要在动作进行中截图才能看到变化。

人物视角来自头部位置与朝向，75° 视场；旁观截图来自当前展示相机。截图分辨率 768×512，JPEG。入口人物可能朝向大厅外，因此人物视角出现纯背景是正常情况，可先用旁观视角验证。

保存截图不调用 API，手动识别和对比各调用一次，使用账户额度。手动检查不自动轮询；启用视觉后，行走途中会按下述频率自动检查。不使用文本模型的 reasoning_effort；默认关闭视觉思考，最多输出 1600 tokens，SDK 不自动重试。模型超时默认 60 秒，手动检查页面等待最多 90 秒。

## 行走障碍测试：发现、停步、恢复

仅启动 `python body_3d.py`，展开“行走障碍测试”，点击“开始障碍测试”。此按钮重载测试场景、开启视觉并发出本地前往咨询台命令，无需连接大脑。人物先转向大厅，随后观察前方橙色路障。路障有真实碰撞体，但不预先加入路径规划地图。

模型输出 `path_obstacle=suspected` 后，由导航层确认当前路线与登记的路障相交，再要求现有控制器停步。完成当前步态并持续站稳后进入等待，导航仍为 `running`，不会误报到达。点击“移除路障，继续行走”同时移除显示和碰撞体，人物恢复原路线。停步处理超过 120 仿真秒仍未恢复则回报失败。

- 页面“触发来源”区分“视觉发现＋几何确认”和“近距离几何保护”。后者不依赖 VLM，即便视觉不可用也会在接近路障时停车；不能把它算作视觉识别成功。
- 途中只在朝向路线时检查，同一命令调用间隔至少 5 仿真秒且至少 3 秒真实时间，一次只处理一个请求。暂停、正在停步或等待时不继续请求；旧命令和过期结果丢弃。建议使用默认 1 倍速，以免请求返回前人物已经转向或截图过期。
- 当前几何确认仅覆盖登记的测试路障，并非对任意未知物体的通用避障。此版本实现停步等待与移除后恢复，尚未实现自动绕行或 VLA 关节控制。
- 可不勾选视觉运行普通导航；测试按钮会自动勾选视觉。结束测试可重置场景。

自动测试：`npm.cmd run test:obstacle` 使用真实 MuJoCo 验证视觉触发与几何保护两分支的停稳、等待、移除后到达；`npm.cmd run test:obstacle-browser` 使用真实浏览器与物理、模拟视觉响应验证按钮和完整流程。显式设置环境变量 `LIVE_VISION=1` 后运行后者才会调用付费视觉服务。

2026-10-23 实测限制：模拟视觉的完整闭环与真实物理两分支通过。真实 GLM 首次测试有 clear/uncertain 和一次 suspected，仍因识别/时效未成功触发视觉停步，最后由几何保护停车；后续浏览器真实请求出现 502。增强条纹外观后，单图 API 能识别前方条纹实体，但仍返回 uncertain（记录 `6c31ac9b34614f5eb1c6a8246688ea5c`，9.883 秒）。因此尚不能宣称真实模型驱动的视觉停步闭环验收通过，仍需改善视野与识别稳定性。测试不会把几何保护当作视觉成功。

## 数据边界

- 同源 POST /api/vision，接收 frames（1–2 张内嵌 JPEG，含 view、time）和 question（最多 1000 字）。人物位置、物体坐标、关节和动作命令不发送给 VLM，避免把真实状态当成视觉识别结果。
- 输出包含 summary、objects、changes、uncertainties、comparison、path_obstacle，并附模型、耗时、token 用量、截图时刻和记录 ID。path_obstacle 为 suspected、clear 或 uncertain，缺省 uncertain；只有 suspected 才请求几何确认，clear 不构成安全保证。
- confidence 是模型自报把握，不是校准概率；画面中的“看不到”不等于场景中“不存在”。不推测精确米数和世界坐标，伸手不代表物品交付。
- 只允许同源本地 JSON 请求，每次最多一个视觉调用。模型结果通过类型校验后显示；失败可重试，不改变对话和人物动作状态。场景重载会清空基准图，并丢弃旧请求显示结果。
- 服务端 logs/vision-*.json 保存结果和用量，不保存图片或密钥。页面图片仅在浏览器中保存，重载后清除。

本地 JPEG 的命令行验证（调用真实 API）：

```powershell
python scripts/probe_vision.py logs/vision-observer.jpg
python scripts/probe_vision.py logs/vision-before.jpg logs/vision-after.jpg
```

命令行图片缺少物理时间，time 使用 0/1 顺序占位；网页截图才带实际仿真时间。

## 2026-10-23 首轮实测

| 样例 | 真实 API 结果 | 耗时 | 总 tokens |
|---|---|---|---|
| 旁观视角银行全景 | 返回柜台、机器人、取号设备、人物、植物 | 6.760 秒 | 1034 |
| 人物视角纯背景 | 返回未识别出物体，objects 为空，没有编造银行物体 | 2.689 秒 | 821 |
| 同一旁观相机抬手前后 | comparison=changed，描述人物伸手变化 | 7.068 秒 | 1571 |

这是第一轮的 3 次样例调用，不是准确率评测。动作变化描述较粗，没有精确辨别抬手角度、左右手或接触。尚未评估目标靠近、遮挡、距离判断和长时间视觉闭环。

自动回归使用模拟模型响应，不调用付费 API：Python 测试校验输入、输出和请求参数；浏览器测试验证真实截图、单图/双图请求、视角变化清理、无效请求拒绝，并保留语音与动作回归。测试图片保存在忽略的 logs/ 下。

官方接口依据：[GLM-4.6V](https://docs.bigmodel.cn/cn/guide/models/vlm/glm-4.6v)。提示词使用结构化输出和不确定性约束，并由 Pydantic 校验结果。
