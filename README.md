# 顾客仿真 Agent

包含完整的 3D 银行对话系统，以及可以单独运行的人物动作调试界面。

以下命令都在项目根目录 `bank_customer_sim-main` 执行。需要 Node.js 22.12+；运行完整系统还需要 Python。浏览器建议使用 Chrome。

已集成同目录 `HumanSimulation-main` 的当前人物模块（161 个源码与公开资产文件）。银行大厅使用包含 34 个腿部肌肉单元、肌梭和每眼六肌的模型；左上角“人物身体驱动”可在关节执行器对照、踝部肌肉、全腿肌肉间切换，并可开关肌梭反射和物理眼球。请先停步站稳，再切换驱动。默认关节驱动作为对照，物理眼球默认开启。

银行的目的地、避障、取号和对话仍由银行模块负责；完整的感觉估计、自然步态和标定实验可在 `npm run dev:character` 的人物调试页使用。后续更新人物可执行 `npm run sync:human`，同步记录用 `npm run check:human` 检查。接入边界、验证和 API 见 [仿真人集成说明](docs/仿真人集成.md)。

银行默认关节执行器步行速度为 0.5 m/s，可用场景左侧“参考行走速度”调整；肌肉模式沿用原项目的 0.25 m/s 上限。转向、靠近家具和身体平衡出现偏差时会减速。仿真时钟沿用原项目的追赶上限，可通过 `window.human.getState().timing` 检查实际运行倍率。

## 1. 首次准备

安装 JavaScript 依赖（完整系统和人物调试共用，只需安装一次）：

```powershell
npm.cmd ci
```

如果要运行完整系统，还需安装 Python 依赖：

```powershell
pip install -r requirements.txt
```

首次使用时，将 `.env.example` 复制为 `.env`，填写 `GLM_API_KEY`；已有配置可继续使用。语音识别需要下载模型，步骤见[语音模型准备](docs/使用说明.md#语音)。

## 2. 启动完整系统（Agent + 人物 + 银行场景）

打开两个终端，分别运行，两个终端都保持开启。

**终端 1：启动大脑**

```powershell
python brain_server.py
```

**终端 2：启动 3D 场景**

```powershell
python body_3d.py
```

浏览器打开 **http://127.0.0.1:8080**，等待人物加载后点击「开始自动对话」。选择「手动：我扮演机器人」可自己打字与顾客交流。

如果暂时没有语音识别模型，终端 1 改用 `python brain_server.py --no-asr`，直接使用文字内容，仍可合成语音。完整对话需要联网，会调用 GLM API。

## 3. 单独启动人物调试界面

只需要安装上面的 JavaScript 依赖，无需启动大脑、配置 API Key 或下载语音模型。

```powershell
npm.cmd run dev:character
```

打开终端显示的 **Local** 地址（通常是 **http://localhost:5173/**），即可使用界面按钮测试行走、伸手、手指、抓杯和表情等动作。

人物相关代码在 `character/` 中，修改源码后开发页面通常会自动更新。按 `Ctrl+C` 可停止服务。

## 其他说明

人物避障测试：仅启动 `python body_3d.py`，展开“咨询台途中障碍测试”，选择场景，点击“只测试人物行走”，无需大脑或VLM。测试大脑闭环时，同时启动大脑，点击“加载场景（再连接大脑）”，人物就绪后连接；可验证到达后继续任务、堵路后求助，以及道路恢复后的重新决策。见[导航闭环说明](docs/导航闭环.md)；感知原理见[局部感知导航](docs/局部感知导航.md)。

视觉初测：启动 `python body_3d.py` 后，展开页面右侧“视觉检查 · GLM-4.6V”，可识别截图或对比动作前后。默认复用 .env 的 GLM_API_KEY，无需启动大脑对话。操作和实测结果见 [视觉验证](docs/视觉验证.md)。

视觉辅助动作：同时启动大脑后，在连接前勾选“启用视觉辅助动作决策”，系统会在决策前、行走完成和动作失败时观察人物视野，再交给 Agent 选择下一步。每次观察会调用视觉 API；不可用时继续原流程。
