# 人体标定：踝部离线基准

这套工具实现了参数配置、公开数据导入、被动→主动→反射的分阶段拟合入口、冻结配置与留出验证，以及原控制器同条件对照。当前交付是**未通过完整验收的单人踝部研究候选**，不是已经获得人体生理真实性的控制器。运行时继续使用 `engineering-v1`。

## 运行

仓库已保留带来源的归一化真实数据，日常拟合无需联网。

```bash
npm run calibrate:ankle
npm run calibration:compare
python3 scripts/calibration/render_report.py
npm run test:calibration
```

打开 `artifacts/calibration/report.html`。报告包含独立试次曲线、加同一观测偏置及无偏置的力矩误差、步行静态容量图，以及五组控制器的闭环测试。`ankle-p1.frozen.json` 是候选，`report.json` 记录配置 SHA-256、输入 SHA-256、训练试次、边界命中和局部敏感性；`controller-comparison.json` 必须匹配同一配置哈希。

首次重新获取原始数据：

```bash
python3 -m pip install -r scripts/calibration/requirements.txt
npm run prepare:calibration
```

下载缓存位于 `assets/calibration/raw/`，已忽略；不进入浏览器包。踝部原始包约 258 MB，按作者公布的 MD5 检查。步行包通过 HTTP Range 只读取所需成员，并由 ZIP CRC 检查，不声称验证了未下载的整个步行包。源数据的文件信息、作者、许可及处理方式见 `assets/calibration/provenance.json`。可指定已有缓存：`python3 scripts/calibration/prepare_data.py --cache /path/to/cache`。

## 参数配置与运行时边界

`src/human/calibration/profiles/engineering-v1.json` 保留原默认值，包含双侧 34 个功能肌群的最大力、最佳纤维长度、肌腱松弛长度、中立位肌腱总长度和固定力臂，以及 Hill、三纤维肌梭、反射、眼球主要动力学和固定布线参数。每类数值有单位、来源、范围含义和适用对象；标为 engineering 的值是工程假设，不能把来源论文当作这些数值的实验依据。范围是工程约束，不是人体置信区间。

中立位总长度 `referenceLength` 独立于 `optimal + slack`，拟合松弛长度时不再连带移动总长度参考。`ankleHill` 只作用于踝肌群，`hill` 用于其余腿部；主动倍率与被动系数独立，防止主动拟合破坏已冻结的被动力学。固定力臂尚未升级为肌肉绕骨路径；原骨架和上层控制器也未在本次个体化。

`validateProfile` 检查范围、数值、通道数量和拓扑。`HumanController(engine, profile)` 可在创建离线实验时载入配置。腿部控制器核对真实 MJCF 的固定肌腱关节与系数、执行器容量；几何或容量不匹配时拒绝运行，必须重新生成模型。当前踝部试验保持眼球 plant 不变。`npm run generate:neuromuscular` 从默认配置生成独立实验模型，原 `human-free.xml` 不变。

候选的共享参数来自**左踝**数据；在双腿仿真中镜像使用是工程假设，并不表示测过右腿。膝髋与其他肌群保持原参数，不把踝部拟合推广为全腿已标定。

## 数据与坐标

1. [van der Zee 等：Gastrocnemius medialis muscle ultrasonography dataset](https://doi.org/10.6084/m9.figshare.26502868)，CC BY 4.0。[原始方法](https://doi.org/10.7717/peerj-cs.2636)：伸膝、踝中立位主动收缩，以及 5、30、120°/s 被动转动。首版使用参与者 1，不声称代表人群。超声纤维轨迹尚未接入，因此不能辨识每条肌肉的最佳纤维长度或真实松弛长度。
2. [Fukuchi 等：Walking Biomechanics Dataset](https://doi.org/10.6084/m9.figshare.5722711)，CC BY 4.0。[原始方法](https://doi.org/10.7717/peerj.4640)。首版使用另一参与者的 T01/T08 左腿平均曲线，完全留出。

踝部原信号共用采集时钟，但各通道有各自采样时间；先按各自时间戳滤波，再对共同覆盖区间插值到 100 Hz。角度/力矩为双向二阶 Butterworth 10 Hz；肌电为 30–500 Hz 带通、整流、10 Hz 低通，再用独立 MVC 记录的各通道峰值归一化。MG/LG 的归一化信号平均后映射至聚合腓肠肌，未测深层肌群的主动输入设为零。肌电是激活代理，不是直接神经指令或肌肉力。

统一使用背屈角度 rad、背屈内力矩 N·m、膝屈曲 rad、时间 s。源测力计以跖屈为正，角度与力矩一起取负。仿真踝轴也以跖屈为正，因此 `q_model = -q_df`、`tau_model = -tau_df`，通过虚功符号测试验证；膝 `q_model = q_flex`（模型膝轴以屈曲为正）。

WBDS 矢状面角度与力矩均使用原文件 Z 通道；力矩的跖屈正方向转换为背屈负方向，N·m/kg 按该参与者质量还原；竖直地面反力使用实验室 Y 通道，N/kg 还原 N。依据为作者的 `wbdsExploratoryDA.m`（figshare file 10167060）。**101 点 Time 是步态百分比，不是秒**。不凭速度猜步态周期，不将这种相位平均曲线输入反射、速度或功率拟合。

归一化数据记录完整源成员 SHA-256，校验器拒绝缺列、非有限数、重复/倒序时间和缺口；训练和留出集禁止共享试次 ID 或源文件哈希。完整试次在拟合前分组，不随机拆相邻采样点。

## 拟合、冻结与不能辨识的部分

`protocol.json` 在拟合前固定窗口、目标归一化、先验权重、搜索范围、搜索次数及工程验收门槛。固定使用主动前 16 秒（两轮 ramp 周期）、被动前 80 秒或文件实际末尾；不根据留出结果选窗口。首秒为启动段；模型踝活动范围外、被动时肌电过高的点不计分，报告保留排除数量和完整曲线。

- **被动阶段**：仅 `pas_005`。拟合共享松弛长度比例、踝部被动系数和观测常偏置。力臂、最佳纤维长度与其他关节不动。未提供的重力/脚板校正不能凭空补出；常偏置只是观测模型的代用项，不等于已经完成真实装置补偿。
- **主动阶段**：仅 `slow_low` 和 `medium_low`，固定被动结果，只拟合共享主动力倍率。该倍率混合肌力、肌电映射及未测肌肉误差，**不能解释为每条肌肉的最大肌力已被测出**。不同时拟合 Fmax、最佳长度、肌腱刚度与激活延迟。
- **反射阶段**：实现有效回路增益/延迟拟合入口，与运行时共享反射函数。只有 `kind=reflex` 且明确核实扰动时间、保留延迟信息（`latencyPreserving=true`）、独立基线驱动的记录才可进入。观测总肌电不得同时作为前馈再叠加反射。现有导入数据不满足该条件，因此本轮状态是 `not-identifiable`，原 Ia/II/γ 和 12 ms 延迟不变。双向滤波肌电不能用来辨识神经延迟。

损失按试次平均，以固定 20 N·m 尺度归一化，再加相对于工程初值的有界先验。优化器只接收对应阶段的 train 试次。之后冻结所有参数，一次性计算 30/120°/s 被动、快速、非对称、正弦任务的 holdout 结果。观测偏置对原模型和候选相同，另列完全无偏置的原始误差。

离线输入为实测角度和肌电代理，使用与运行时相同的 Hill 模型；100 Hz 输入线性插值到不大于 2 ms 的积分步长。它不调用理想局部伺服，不从实测关节力矩反解激活。局部训练敏感性用于提示参数混淆，未计算统计置信区间，不能证明参数唯一。

## 验证与当前结论

本轮部分任务改善，另一些退化；完整人体标定门槛未通过，`deployable=false`。不能只看慢速误差下降、仿真站稳或力矩可达就宣布“人体标定完成”。

独立步行数据目前只检查静态力矩范围：按各自体重比较 N·m/kg，展示满足/超出容量的比例及模型活动范围之外的比例。没有相位时长和肌电，不做行走动态预测或力量时序验证。另有 `LegBenchmark.ts` 将髋、膝、踝矢状面需求同时放入有界非负分配，使用共享双关节肌肉检查联合静态残差。其他关节角取中立位，未观测额状面/横断面/脚趾力矩，不约束真实募集或时间连续性；分配变量不是人体肌肉力测量，不能证明整个人能完成该步态。

闭环对照在同一神经肌肉模型上比较原位置执行器、原/冻结候选踝部肌肉、原/冻结候选全腿肌肉。使用相同初始状态、感觉随机序列、0.25 m/s 指令、35 N / 120 ms 侧推、转头、停步；另测双倍延迟/4 倍噪声及闭眼站立。按固定时间施加侧推，并非严格同一步态相位冲击。记录跌倒、最低骨盆、位移、步数、原腿电机出力、分配残差和学习记忆变化。保留相同上层控制和理想局部肌长伺服，未向根节点加入辅助力。

## 下一轮扩展的证据要求

先补上装置重力/脚板补偿和超声纤维长度、肌腱位移，用多踝角度、屈膝/伸膝条件区分比目鱼肌和腓肠肌，再以新的独立数据验证。反射需要保留原始高采样率与延迟信息的受控扰动记录；行走需要同步真实时间、运动学、地面反力及肌电。膝髋标定沿用同一配置/试次/冻结/对照机制，新增相应力矩与肌肉观测后再启用，不直接沿用踝部拟合比例。物理眼球另建眼动与头动实验，本次只将其主要参数移入配置，不以腿部数据标定眼球。
