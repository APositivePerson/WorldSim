# 真人参考与实时运动控制

当前实现针对现有 MuJoCo 简化人体的平地直行。默认改为 0.5 m/s 的连续行走，可调 0.25–0.5 m/s；75 kg 以上保守限制到 0.25 m/s。原有 0.015–0.045 m/s 控制保留为「慢速平衡实验」。默认连续行走的速度和步幅显著改善，但仍是舒缓行走，不能把本版描述为完整真人步态复现或已经达到正常成人步速。

## 连续行走

`NaturalWalking` 用连续的前进位置、速度与加速度参考替代逐步停顿式前移。起步按 0.65 m/s² 渐变加速，停步按 0.9 m/s² 渐变减速；每步周期在开始时固定，通常约 0.57–0.60 秒。脚经过双脚支撑、平滑抬起、前摆和真实接触确认，落脚位置按预期落地速度规划，最高抬脚参考约 3.5 cm；必须实测接触载荷持续达到阈值才能计步。

下肢 IK 每 10 ms 更新，在独立 MjData 中求解参考姿态，不改写主仿真 qpos。除重力和足端 wrench 前馈，还增加 `kv / kp × 参考关节速度` 补偿，减少位置电机阻尼引起的快速动作滞后。平衡器支持参考水平加速度，保留单向接触、摩擦与压力中心约束。摆臂与躯干仍由 CMU 实测参考和用户控制权仲裁生成。

质量变化时，大体重模型的下肢位置电机刚度与阻尼按 `mass / 65.41` 增强，轻体重保留基础增益，力矩上限不变；停止、重置、跌倒和卸载时恢复原始增益。大体重模型在更高速度下尚不够稳定，因此主动限制速度，并在界面明确显示。实测速度独立于参考速度显示，不通过提高仿真倍速或移动渲染人物来制造提速。

默认质量的真实物理回归：130 秒前进约 64.8 m、209 次落脚，最低骨盆高度约 0.910 m；双脚均有真实离地，关节保持限位，停止后能站稳并重新起步。45 kg / 100 kg 端点、动作接管、微小侧推实验和旧慢速控制继续单独验证。更高速度的试验曾出现偏转、落地延迟及跌倒，未作为可选档位发布。

骨盆高度由当前双脚间距和腿部可达距离决定，上限 0.94 m，替代固定低骨盆造成的持续屈膝。着地后用 100 ms 平滑锁定到实测足部位置。修复换脚帧提前切换参考侧的问题，摆臂和躯干相位在落脚边界保持连续。停步请求先完成当前摆腿，再在下一步内减速，避免原落点与提前停止的骨盆相互牵扯。随后保留双脚支撑控制，限速移向双脚中心；身体余速消退后才恢复站立增益。

连续行走的支撑力分配加入 `M(q) × 参考加速度 + qfrc_bias` 前馈，计算摆腿对浮动根部的反作用，再通过真实支撑脚分配力和力矩。角力矩从根部局部坐标转换到世界坐标；踝部 wrench 的压力中心约束包含足底高度产生的力臂，不能直接把踝部力矩当作地面力矩。期望腿部加速度经限幅和平滑处理，力矩仍通过原有电机限制执行。这是近似逆动力学前馈，尚未求解全身受约束加速度 QP。

连续行走还接入左右脚独立的有界落脚时序和载荷学习，界面可学习、冻结或关闭。接触时刻来自实测足底载荷；修正在下一次起摆时锁定。详情和误差含义见 [小脑功能原型说明](cerebellum.md)。

## 足底滚动、蹬离与受扰落点

连续步态默认启用脚跟着地、全掌承重、前掌蹬离。模型前进方向为 −Y；脚跟着地参考俯仰约 −0.04 rad，前掌蹬离约 +0.10 rad，低速和起步按速度渐变缩小。足端位置按接触点旋转求出：脚跟阶段保持后缘接地点，蹬离阶段保持跖趾关节高度并让脚趾反向背屈，使前掌留在地面。脚趾真实关节与电机范围扩展为 −0.5 至 +0.65 rad；生成脚本与两个模型保持一致。角度变化率不超过 0.8 rad/s。足端 IK 和脚趾位置电机共同实现动作，足部图形继续跟随真实物理。

摆动前 65% 可根据实测 capture point 与移动参考之差调整落点。参考保留当前质心到骨盆的偏移，并使用目标速度预测 capture point。误差死区 8 mm，落点横向最多 ±18 mm、前后最多 ±25 mm，变化速度不超过 35 mm/s；后段冻结落点，避免临近落地时抽脚。停止减速时不启用新的落点修正。它是有界反射反馈，和跨步载荷学习分开工作。

「步足近景」从侧面跟随人体，便于检查脚跟落地和前掌蹬离；默认视角恢复全身观察。界面显示足部**参考**阶段和落点修正，足底压力与接触仍来自实测。停步后可以分别关闭「足底滚动与蹬地」「受扰落点调整」做对照：

```js
window.human.setWalkingMechanics({rolling: true, reactiveStepping: true});
window.human.getState().locomotion.mechanics;
```

运行中或输入非法时返回 false。每轮走路开始会清除上轮落点修正，保留已学习的载荷和时序记忆；重置物理状态才清除学习记忆。

真实物理验证覆盖足底滚动开 / 关、承重时脚跟接地与前掌接地、脚趾背屈、35 N × 0.12 s 的正反侧推、下一次真实落脚朝受推方向变化并继续行走，以及三个体重的十二种停步组合。基础方法参考 [capture point 原始研究](https://www.cs.cmu.edu/~hgeyer/Teaching/R16-899B/Papers/Pratt%26Goswami06Humanoids.pdf)；力读取遵循 [MuJoCo 接触力约定](https://mujoco.readthedocs.io/en/latest/computation/index.html)。本实现的具体增益和范围经过当前模型验证，不能外推为原论文算法或通用恢复能力。

## 参考数据

来源为 CMU Graphics Lab Motion Capture Database 的 subject 07 / trial 01（walk，120 Hz）。原始 ASF、AMC、供应商使用条款链接和致谢位于 [assets/motions/cmu](../assets/motions/cmu/README.md)。该数据与派生参考不属于程序皮肤的 CC0 资产。项目保留原始文件哈希，测试核对来源文件与转换产物记录一致。

运行 `python3 scripts/prepare-walk-reference.py` 可重建 `src/human/motion/cmu-walk.json`。转换过程解析 ASF 骨骼轴、父子关系与 AMC 通道，用 `C R C⁻¹` 前向运动学取得肢体方向，选取连续左膝屈曲峰之间的一次完整实测周期，再做循环接缝漂移消除、周期低通和 128 点相位采样。排除 CMU 未真实采集的手指/拇指通道。肩肘、腰胸和足部高度曲线保留了实测不对称性，运行时按本模型能力降低幅度、降低速度并重映射接触相位。

## 每个物理步如何工作

以下阶段细节中的转移支撑和下一步位置反馈对应保留的慢速平衡实验；默认连续步态使用上节的 `NaturalWalking`。两者共用传感与姿态协调。

1. `LocomotionSensors` 约每 10 ms 读取真实地面接触、足底载荷和压力中心，估计质心速度、capture point 与脚部水平速度。接触检测带有滞回。所有临时 WASM 接触句柄均在读取后释放。
2. `LocomotionController` 使用转移支撑、摆动、落地确认三个阶段。抬脚需要实测支撑载荷及 capture point 落在规定范围内；计步需要实测落地载荷持续成立。平衡不足会等待，不按播放时间伪造落脚。
3. 下一步位置包含有界 capture-point / 速度反馈，着地后把支撑参考锁到观测到的足部位置。参考速度渐变，每段持续时间在开始时固定，因此中途调速不会倒放或跳变抬脚相位。单支撑时重心继续前移。
4. `LegIK` 在独立 MjData 内求解脚位置与小幅摆动脚俯仰，平滑跟踪骨盆高度。只输出关节参考，不改写真实人体坐标。
5. `BalanceController` 根据根部位姿、速度、质心和偏置力计算期望支撑 wrench。32 次投影梯度迭代求解带正法向力、摩擦棱锥、压力中心及扭矩界限的足端力分配；无接触的脚不分配支撑力。通过 `qfrc_bias − Jᵀ wrench` 生成关节力矩前馈，再除以实际 actuator kp 叠加到位置目标。
6. `WholeBodyCoordinator` 根据同一参考相位生成肩肘、腰胸屈伸/侧弯/扭转，并叠加有界躯干姿态反馈。`HumanController` 仲裁关节控制权，手动和伸手/抓杯任务优先，腿部平衡继续执行。

本版采用受约束的质心支撑力分配与关节姿态协调；没有声称实现全刚体加速度层面的逆动力学 QP，也未训练神经网络。正常运动不使用根部外加支撑力，不把人物沿动画轨迹搬运。实际动作仍由 `mj_step`、关节驱动器和地面接触产生。

## 界面与接口

「平衡与步行」提供步态、参考速度、实测速度、真人动作参考强度和实时左右脚支撑力。步态必须在停止后切换；同一种步态内可以边走边调速。下列接口仍支持原有小步范围。`setWalkingLearning("learn" | "frozen" | "off")` 控制连续步态的落脚时间校准。

```js
window.human.setWalkingSpeed(0.5);      // 连续行走：0.25–0.5 m/s，受当前质量的速度上限约束
// 停步站稳后也可 setWalkingSpeed(0.03)，切换为原有慢速平衡实验
window.human.setMotionReference(1);     // 0–1
window.human.executeAction({ action: "walk_forward" });
window.human.getState().locomotion;    // motion / balance / 接触 / 落脚修正
window.human.executeAction({ action: "stop_walk" });
```

非法或非有限参数返回 false。固定基座模式没有行走控制器，对应设置返回 false。暂停冻结物理时间、参考相位和姿态。

## 验证与局限

`tests/natural-balance.test.ts` 还覆盖真实踝部 wrench 的足底压力中心约束、行走学习冻结 / 关闭，以及 45 / 65.41 / 100 kg 的四个停步相位。`tests/locomotion.test.ts` 在每个物理步检查摆臂参考连续性，并验证长程步行确实更新落脚学习记忆。

`tests/motion-control.test.ts` 覆盖源数据哈希、周期连续性、参考实际参与控制、三个速度端点、行走中 25 N / 0.1 s 侧推、落脚修正、支撑力约束、停止及手动躯干控制权。原有 60 秒站立、130 秒持续步行、35 N / 0.1 s 站立侧推、体重端点、抓杯和伸手回归继续保留。浏览器测试检查界面参数、参考开关、暂停冻结和真实足底载荷；扫描人物的动态录像位于本机私有 `artifacts/scanned-private/review/motion-control.webm`。

接触门控是保守策略，动作会慢于原始真人采集。还未覆盖转向、坡地、楼梯、奔跑、强推搡或任意大幅组合动作。摩擦棱锥和足底范围是当前碰撞模型下的约束近似，固定迭代优化通过残差暴露误差，不声称精确动力学最优解。步态数据来源不改变扫描人物的比例拟合与测量精度限制。
