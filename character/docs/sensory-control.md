# 感觉接口、身体状态估计与头眼稳定

当前实现包含初始平地站立及感觉驱动行走，见 [行走实现与验收](sensory-walking.md)。原控制器默认保留，取物和肘部肌肉实验仍使用原路径。腿部仍由原有位置执行器驱动，尚未成为肌肉—脊髓反射控制。本页原场景没有完整视网膜图像处理、肌梭神经元或肌肉驱动眼球；新增的独立 [神经肌肉实验](neuromuscular-control.md) 提供简化肌梭、全腿肌肉和物理眼球。

## 操作与对照

在自由站立场景等待站稳，打开「感觉与头眼稳定」：

1. 从「原控制器 · 精确状态对照」切换为「感觉估计 · 站立与行走」。入口要求位于初始站位附近、速度较低，且没有步行、取物、肌肉或侧推实验冲突。切换失败不会隐式重置已有状态。
2. 选择全部感觉、闭眼，或噪声 4 倍 / 延迟 2 倍。后者是工程压力测试参数，不是人体固定的生理常数。
3. 点击「转头并保持注视」，真实颈部偏航目标为 0.35 rad，注视点固定在世界坐标 `[0,-3,1.65]`。可用「头肩细节」观察眼球补偿，关闭「头眼稳定」做相同目标的对照。
4. 点击「侧推对照」，向骨盆 +X 施加 35 N、持续 120 ms 的真实外力。两种控制模式都可运行。橙色箭头只在真实施力时显示，舞台记录两秒观察窗内的最大横移。
5. 暂停冻结物理、感觉队列、估计、眼动和实验时钟。重置清除感觉校准；切回原控制器释放感觉状态。停止、重置和卸载会移除实验自身的外力分量，不删除其他模块的分量。

感觉模式允许自然步态行走、站立及兼容的上肢 / 头部姿态操作，拒绝慢速旧步态、伸手、抓杯和原有重复侧推学习实验。行走中锁定控制模式，停步后可切回原控制器，保留已经到达的世界位置。头眼稳定开启时接管颈部俯仰和侧倾，偏航可自主转动。

## 输入、延迟与坐标

[感觉接口](../src/human/sensory/SensoryInterface.ts) 是新控制路径中读取真实物理状态进行感觉转导的模块；数据包携带采样时刻、送达时刻和噪声尺度。延迟未到的数据不会送给估计器。噪声采用固定种子，便于复现。

| 通路 | 当前近似 | 默认传递延迟 |
| --- | --- | --- |
| 本体感觉 | 各关节角度、速度的带噪声代理；尚不是肌肉长度 / 肌梭放电模型 | 12 ms |
| 头部惯性 | 头坐标旋转速率及比力 `Rᵀ(a-g)`；保留倾斜与平移的感觉歧义，尚未实现完整半规管受体动态 | 6 ms |
| 足底 | 左右脚各四区的接触载荷、承重与全掌接触判别 | 14 ms |
| 视觉 | 每 20 ms 采样的已匹配地标位姿与目标视网膜角误差代理；不渲染再识别图像 | 60 ms |

进入感觉行走后，前庭角速度用于身体估计前会等待并匹配不晚于本体感觉采样时刻的样本，以减少颈部运动和不同延迟相减造成的假旋转。表中是各通路最早送达延迟，不表示融合时每条通路始终使用最新样本。

默认噪声为有界均匀扰动：关节角 ±20 µrad、关节速度 ±0.0005 rad/s、头部旋转速率 ±0.0002 rad/s、比力 ±0.006 m/s²、地标位置 ±0.3 mm，以及每个足底分区 ±0.025 N；另加入可校准的旋转速率零偏。这些是低噪声工程起点，未标定为人体感觉阈值。

身体 / 足底 / 惯性感觉约每 4 ms 采样。关闭视觉同时移除地标位姿与视网膜误差；前庭眼反射仍能短时提供头动补偿，但失去视觉纠偏后会产生漂移。关闭通路会清除该通路的待送达样本；重新打开后必须等待新样本及其传递延迟。

## 状态估计与反馈边界

[身体估计器](../src/human/sensory/BodyStateEstimator.ts) 只接收模型、关节描述和感觉帧，没有真实 `MjData` 入口。它在独立数据中计算：

- 利用已标定的初始双脚支撑、关节运动学及足底接触进行站立里程计。
- 积分头部旋转速率，扣除估计的颈部 / 躯干相对运动，并融合全掌接触、地标与比力信息。
- 根据观测采样时间进行有限的状态外推，估计基座位置、姿态和速度。
- 输出感觉可用性与启发式误差预算；该预算不是经过统计标定的协方差或置信区间。

[感觉站立控制](../src/human/sensory/SensoryBalance.ts) 将估计数据传给平衡器。质量矩阵、关节 Jacobian、偏置力和质心均在估计状态上计算；上肢重力补偿也切换到估计数据。没有以“感官不足”为理由偷偷回退到精确状态控制。

真实物理状态仍供渲染、界面评估、显式侧推实验及独立跌倒监测使用。[评估模块](../src/human/sensory/SensoryDiagnostics.ts) 计算真实位置估计误差、视线夹角与头部倾斜，不把结果返回估计器或反馈控制。

初始站立里程计假定已标定水平地面和近似固定的支撑脚；行走扩展按延迟载荷更新支撑点，并保存有限历史校正延迟视觉。它不能作为未知坡地、持续滑动、长时间腾空或通用全地形状态估计已经解决的证据。感觉缺失的组合也并非都保持可观测。

## 头眼稳定

[头眼控制](../src/human/sensory/HeadEyeStabilizer.ts) 用延迟头部惯性前馈和视网膜误差反馈产生眼动，眼球具有速度限制和一阶响应。偏航 / 俯仰范围分别限为 ±0.60 / ±0.35 rad，速度最多 3 rad/s。这些数值是本版工程参数。

头部侧倾与俯仰通过真实颈部位置执行器作有界补偿；自主偏航不会被强制归零。眼球角度模型通过显示骨骼呈现，渲染器在感觉模式中不再根据真实目标坐标直接求理想眼球朝向。眼球尚不是 MuJoCo 肌肉驱动的独立刚体。

## 短暂扰动与长期校准

感觉站立和行走只开放稳定期的陀螺零偏校准，没有训练新的长期腿部补偿；感觉行走不接入原有落地时序和载荷学习器。检测到加速度、身体运动、关节运动、感觉缺失或接触异常时，拒绝更新；恢复后还要求稳定期与冷却时间。

运动检测依赖已经到达的感觉，因此不可在感觉传递之前预知外力。原有行走时序、载荷与提示侧推记忆在感觉站立期间不更新，侧推刺激的力、标签和时刻没有传入估计器。本版实现的是明确范围内的更新隔离，不是已经完成身体变化 / 外界扰动 / 感觉故障的通用原因分类器。

## 验收与复现

```bash
node --import tsx --test --test-isolation=none tests/sensory-control.test.ts
PLAYWRIGHT_PORT=4186 CHROMIUM_PATH=/opt/google/chrome/chrome npx playwright test tests/browser/sensory.spec.ts
```

真实 MuJoCo 检查包含原控制器、完整感觉、闭眼、关闭前庭，以及噪声 4 倍 / 延迟 2 倍。每个条件先连续站立 30 秒，再施加 35 N / 120 ms 侧推，观察恢复、零偏更新隔离和原有运动记忆。测试预置非零的运动记忆，检查它们没有被清空或改写。

相同感觉条件下，头眼补偿开 / 关的对照要求头部真实转动、有限眼速以及注视误差下降。另有数据送达时间验证、估计状态与真实状态的因果隔离、暂停、模式切换、外力清理与重置检查。

初始站立版本的一次确定性验收中，头部转动 0.35 rad 时，关闭 / 开启头眼稳定的两秒平均视线误差约为 16.07° / 0.13°，开启后的峰值约 0.54°。侧推后的最大横移约为原控制器 3.1 mm、新感觉模式 4.2–4.3 mm；两者均恢复站立。这体现了本版延迟感觉的性能代价，不能解读为新模式各项指标都优于精确状态对照。

原始测量保存在 [站立与恢复](../artifacts/sensory/balance.json) 、[头眼对照](../artifacts/sensory/gaze.json) 和 [实际头部倾斜对照](../artifacts/sensory/head-tilt.json)。误差单位分别为米、弧度；独立评估使用真实身体状态和有限速度眼球状态。浏览器录像为 [感觉站立与头眼稳定](../artifacts/sensory/standing-and-gaze.webm)。

```js
window.human.setSensoryMode(true);
window.human.configureSenses({vision:false});
window.human.configureSenses({vision:true,noiseScale:4,delayScale:2});
window.human.configureSenses({headEyes:false});
window.human.startBalancePush();
window.human.getState().locomotion.sensory;
window.human.getState().balancePush;
window.human.setSensoryMode(false);
```

设置非法参数或不满足切换条件返回 false。重置保留当前控制模式和感觉条件，但清除感觉历史、眼动状态、零偏校准和实验记录。
