# 踝部／全腿肌肉、肌梭与物理眼球

这是独立的第一版神经肌肉实验，资产为 `public/models/human-neuromuscular.xml`。原自由站立、固定演示与取物场景继续使用原 MJCF。实验覆盖双腿所有现有关节轴和真实眼球动力学，不代表完整人体解剖、脊髓或小脑神经网络已经复现。

## 操作

1. 「基座模式」选择「神经肌肉实验 / 自由站立」，等待站稳。
2. 「腿部驱动」可选原关节执行器、踝部肌肉与肌梭、全腿肌肉与肌梭。踝部模式关闭双侧踝俯仰／侧倾共 4 个位置电机；全腿模式关闭髋、膝、踝、趾共 14 个位置电机。模式切换不修改真实 qpos，行走或侧推期间拒绝切换。
3. 查看实际电机出力、肌力、肌腱伸长、Ia／II 和反射贡献；可改变静态／动态 γ 驱动，关闭反射做消融。
4. 可启用感觉估计后行走。肌肉模式当前最高参考速度为 **0.25 m/s**；选择停步后才能返回原执行器。
5. 「物理转头并注视」检查前庭眼反射；「近处目标与集合」检查双眼独立转动；「头肩细节」适合观察。关闭六肌控制时仍保留真实眼眶弹性及肌肉被动力。

## 腿部力学

`LegAnatomy.ts` 每侧 17 个肌肉／功能肌群，共 34 个单元：比目鱼肌、腓肠肌、胫骨前后肌、腓骨长肌群、髂腰肌、臀大／臀中肌、内收肌群、腘绳肌、股直肌、股广肌群、股二头肌短头、髋内外旋肌群和趾屈伸肌群。腓肠肌跨膝踝，股直肌与腘绳肌跨髋膝；同一条肌肉的拉力同时影响多个关节。

每单元包含：

- 有限速度的兴奋—激活动态，激活与去激活时间常数分别为 12 / 35 ms。
- 主动力—长、力—速曲线和并联被动力。
- 非线性串联肌腱弹性；隐式力平衡求肌纤维长度，肌梭使用这条肌纤维长度，而不是把关节角直接重新命名为肌梭。
- 通过 MuJoCo 原生 tendon transmission 施加拉力，肌肉只产生非负张力，力矩由 `-dL/dq × tension` 得到。肌腱与关节均不写入隐藏的辅助 `qfrc_applied`。

MuJoCo 标准肌肉将生物肌腱近似为不可伸长，因此腿部在 TypeScript 中计算串联弹性平衡，再把力送给原生执行器。不是把原生 tendon 的并联弹簧误称为串联肌腱。[MuJoCo 肌肉建模说明](https://mujoco.readthedocs.io/en/stable/modeling.html#muscle-actuators)

原腿部位置执行器通过独立 actuator group 真正停用，保留其参数供工程控制器形成参考，不通过关闭 gain 后除以零来改变平衡器。关节原有被动阻尼保持不变；没有添加额外关节阻尼或隐形骨盆力维持站立。力分配使用有界非负优化；容量不足时报告残差，不额外调用电机补足。

**控制边界：** 上层仍沿用原工程步态和平衡器，感觉模式的身体反馈继续来自独立估计器。执行器内部保留理想的局部肌长伺服：以当前肌腱长度／速度和已知传动系数形成局部反馈。该快速局部回路与后述有延迟的 Ia／II 反射并存，不能称为“完全依赖生理肌梭的脊髓控制”。身体估计器中的关节本体感觉代理也尚未全部替换为由肌梭放电解码的感觉。

## 肌梭和反射

`MuscleSpindle.ts` 的 bag₁、bag₂ 和 chain 三个梭内单元各有极区长度、感觉区弹簧张力、非线性黏性和 γ 激活动态。使用隐式串联力平衡更新状态，动态 γ 主要影响 bag₁ 的速度敏感性，静态 γ 调节 bag₂／chain 的响应。梭内张力为归一化单位，Ia／II 的 Hz 标度尚未用人体放电记录校准。Ia 与 II 由这些状态形成有界频率信号，保留静态长度、速度、γ 与缩短松弛的相互影响。

结构参考 [Mileusnic 等的三纤维肌梭研究](https://pubmed.ncbi.nlm.nih.gov/16672301/)。本实现采用自有简化方程及实验参数，未复现其完整拟合参数，也不是放电神经元网络或经人体数据验证的模型。

α 激活同时调节 γ 驱动，用户可调基线。Ia／II 及归一化腱力反馈经过 **12 ms** 队列，参与有界的拉伸反射、拮抗抑制及过载抑制。当前没有完整 Ib 受体动力学、Renshaw 回路、相位相关脊髓回路或神经传导个体标定。局部反射对兴奋的修正上限为 ±0.035；它改变实际肌力，不只是记录曲线。关闭／重新开启反射会清空对应待送达信号。

## 物理眼球

每眼增加一个真实刚体和 yaw / pitch / torsion 三个转轴，具有惯量、眼眶被动弹性与阻尼。每眼六条肌肉为内外直肌、上下直肌、上下斜肌，使用眼球插入点和眼眶固定滑车点构成空间肌腱；肌力通过当前几何力臂作用于真实眼球。

神经位置积分器融合前庭角速度与延迟的双眼视网膜误差，形成有限速度目标，再分配六肌兴奋。双眼各自观测目标，近处注视可出现集合。六肌分配保留理想的局部眼角／角速度反馈，不是仅靠延迟视觉的生理眼动神经回路。角度由物理推进产生，蒙皮直接绑定眼球刚体，显示层不能根据目标写一个理想眼球朝向。视觉仍是方向／地标代理，不是像素视觉。

空间六肌和眼眶组织的结构参考 [OpenSim 眼动模型研究](https://arxiv.org/abs/1807.07332)。本项目的几何、滑车位置、力常数和控制参数是独立工程近似；不是该模型的移植或临床校准。眼外肌采用 MuJoCo 原生肌肉，仍使用其不可伸长生物肌腱近似。固定滑车、三转轴与被动组织也不等于完整眼眶解剖和主动滑车动力学。

新眼球质量从原头部质量中划出，总质量仍为 65.41 kg。可独立削弱某条眼外肌，不通过修改眼球角度伪造病变效果。当前不包含眼内调节肌、瞳孔光反射和完整视网膜。

## 验收

```bash
node --import tsx scripts/generate-neuromuscular.ts
npm run build
node --import tsx --test --test-isolation=none tests/neuromuscular.test.ts
PLAYWRIGHT_PORT=4186 CHROMIUM_PATH=/opt/google/chrome/chrome npx playwright test tests/browser/neuromuscular.spec.ts
```

物理专项验证包含肌肉激活滞后、肌腱伸长与被动力，快慢拉伸与 γ 对肌梭的作用，反射消融，踝／全腿与感觉估计组合的站立、35 N / 120 ms 侧推、12 秒行走和停步，以及暂停、重置、回到原执行器。逐帧检查被接管电机出力为零、关节被动阻尼没有额外增加；独立核对关节力矩等于真实肌肉传动力矩之和。

眼动对照采用相同 0.35 rad 真实转头，比较控制关闭、正常六肌控制及右外直肌失力；记录实际眼球视线误差和速度，另检查近处集合、渲染与物理一致、配置不瞬移眼球。

默认质量 65.41 kg 的本次确定性结果：

| 条件 | 12 秒前进距离 | 落脚总数（含停步） | 最低骨盆高度 |
| --- | --- | --- | --- |
| 踝部肌肉 | 2.95 m | 21 | 0.925 m |
| 全腿肌肉 | 2.94 m | 21 | 0.925 m |
| 全腿肌肉＋感觉估计 | 2.94 m | 23 | 0.924 m |

三组均完成侧推恢复和停步；活动肌腱峰值伸长约 4.2%。六肌眼动控制开／关的两秒平均实际注视误差约 0.32°／16.09°。右外直肌失力时，右眼最终误差约 22.9°，左眼仍能注视。这些是本模型内对照结果，不是人体准确性或临床预测能力的证明。

原始数据：[腿部](../artifacts/neuromuscular/legs.json)、[眼球](../artifacts/neuromuscular/eyes.json)。交互录像：[全腿与眼球](../artifacts/neuromuscular/full-leg-and-eyes.webm)。

## API

仅神经肌肉场景提供对应执行器：

```js
window.human.setLegDrive('ankle');  // 或 'full' / 'servo'
window.human.configureSpindles({reflexes:true,gammaStatic:.3,gammaDynamic:.4});
window.human.setSensoryMode(true);
window.human.executeAction({action:'walk_forward'});
window.human.executeAction({action:'stop_walk'});
window.human.setEyeTarget([0,-.5,1.65]);
window.human.setEyeMuscleStrength('eye_right_lateral_rectus',0);
window.human.setPhysicalEyeControl(false);
window.human.getState().legMuscles;
window.human.getState().physicalEyes;
```

`legMuscles` 中包含实际肌力、兴奋、激活、纤维／肌腱状态、梭内状态、延迟传入、反射贡献及分配残差。`physicalEyes` 包含每眼实际角度／速度、目标及六肌兴奋／激活／拉力。弱肌参数保持到显式恢复或卸载场景；物理重置清除瞬时肌肉、肌梭、感觉队列及眼动积分状态。

## 适用范围

这是默认身体、已标定平地上的功能模型。腿部使用常力臂和肌群聚合，未做真实空间肌腱绕骨、关节轴迁移、羽状角或个体参数拟合；目标超出肌力容量时会有分配误差。目前不保证未知地形、任意体重、肌腱损伤或任意感觉缺失下的稳定，也不把反射回路当作已经训练的新小脑。后续需要用人体力矩／步态数据标定力臂和容量，并以独立实验验证局部伺服逐步被生理反馈替代后的表现。

## 人体标定入口

肌肉、肌梭、反射及眼球主要参数已移入 `src/human/calibration/profiles/engineering-v1.json`，保留原默认值作对照。公开人体数据、踝部离线拟合、冻结候选和闭环对照见 [人体标定说明](human-calibration.md)。当前候选未通过完整验收，不自动替换默认控制器；膝髋、肌梭神经参数和物理眼球均未因此完成个体标定。
