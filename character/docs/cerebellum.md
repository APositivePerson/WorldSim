# 小脑功能原型：落脚时序、载荷校准与侧推适应

本版实现可学习的前馈补偿和独立的短时运动预测器，不是小脑组织、浦肯野细胞或完整神经回路仿真。范围是现有人体模型在平地双脚站立时，对具有共同开始提示的重复侧推进行适应。侧推补偿只在侧推实验中启用；连续行走另有独立的落脚时序与足底载荷学习器。

「感觉与头眼稳定」另有独立的站立实验与稳定期陀螺零偏校准；该模式不更新这里的行走或侧推记忆。范围见 [感觉闭环说明](sensory-control.md)。

## 连续行走的落脚时序学习

`WalkingCerebellum` 默认处于「学习并校正」。它读取左右脚真正离地后重新接触地面的时刻；接触载荷需持续超过体重的 5% 达 12 ms，身体高度与倾斜也须满足有效条件。按左右脚和速度区间分别估计计划落地与实际接触之间的延迟。学习时扣除本步已施加的时序修正，避免把自己的控制效果误当成模型延迟。

至少观察同一上下文两次接触后，下一步应用估计延迟的一半，校正范围为 −10 至 +20 ms。正值提前结束摆腿，负值延后；本步起摆时锁定参数，中途更新或切换模式不会让正在摆动的脚跳变。记忆估计范围为 −20 至 +60 ms。它是有界的在线时间校准，不是神经网络或完整生物小脑。

界面提供「学习并校正」「冻结已学模型」「关闭校正」。冻结后继续记录真实接触和预测误差，停止更新参数；关闭后下一步不施加时序修正。面板显示落脚学习次数、实际应用的时序修正和预测误差。预测误差是接触延迟模型的指数平滑绝对残差，不能当作身体摇晃或步态自然度的评分。

```js
window.human.setWalkingLearning("learn"); // learn / frozen / off
window.human.getState().locomotion.cerebellum.walking;
```

暂停冻结物理和学习。停步保留记忆，重置人体或清除学习记忆会清除；行走和侧推实验中不能清除。落脚时间和载荷校准目前只覆盖平地直行，不学习障碍绕行或任意侧推。足底滚动的基本轨迹由控制器提供，学习模块只做小幅校准。

## 足底载荷学习

`WalkingLoadLearning` 将上一次支撑力分配的计划竖直力，与随后实测的足底载荷配对；约每 10 ms 采样一次，用全身体重力归一化。左右脚、三个速度区间、脚跟承重 / 单脚支撑 / 后脚蹬离阶段分别保存记忆，每阶段另有 8 个时间分箱，预测实际载荷相对计划力的残差。预测误差在参数更新之前计算。没有接触、计划载荷低于体重力 5%、身体倾斜过大、减速和停步稳定期间的样本不提交。

跨阶段的平滑载荷偏差用于有界启发式校准：计划蹬地力大于实测时，小幅增加下一步前掌蹬离角；左右脚承重偏差用来微调横向重心转移。蹬离角校正最多 ±0.004 rad，单脚转移校正最多 ±1.5 mm，合成重心修正变化不超过 1 mm/s。动作参数在起摆时锁定；基本足底滚动轨迹不依赖学习开关。

同一个「学习并校正 / 冻结已学模型 / 关闭校正」开关同时控制时序和载荷校准。冻结保持记忆和校正，继续观测；关闭后下一步两类学习校正都归零，反射式落点反馈仍独立工作。`walking.load` 提供更新次数、体重力单位的预测误差、阶段偏差和时间分箱参数。`uncorrectedError` 是同一次运行中未加残差预测时的误差，不是关闭校准的独立物理对照结果。该模型和策略尚未证明对任意地形或所有推力都能降低物理载荷误差。

`tests/walking-learning.test.ts` 验证已知载荷缺口下的闭环校准、左右脚 / 速度隔离和冻结；真实 MuJoCo 测试验证载荷确实更新模型、动作校正非零、冻结后模型不变以及关闭后校正归零。`artifacts/walking-mechanics.json` 保存足底滚动开 / 关的实测接触计数、脚趾背屈和载荷模型记录。

## 侧推实验操作

自由站立场景加载并站稳后，在「小脑学习实验」依次运行：

1. 「原有控制」：不施加学习补偿，记录基线。
2. 「持续学习」：每轮结束后根据身体偏移更新下一轮的补偿，在线更新预测器。
3. 「冻结学习」：应用已有补偿，冻结补偿参数和预测器参数。

每组默认 8 轮，每轮 4 秒仿真时间；从提示后 0.8 秒起，向骨盆 +X 方向施加真实外力。默认「明显侧推」为 100 N、持续 0.25 秒；「微小侧推」为原版 35 N、持续 0.1 秒。切换档位会清除旧补偿和对照记录，避免跨协议比较。

原版微小侧推仅产生约 2–3 mm 位移，且全身相机会跟随根部，不容易看出晃动。现在实验开始时切换正面固定视角，取消训练期间的相机跟随；真实施力期间显示橙色箭头。人物仍严格跟随真实物理位姿，没有放大人物动作。默认质量的明显侧推可产生约 25 mm 横移，8 轮学习可完成且保持站立；该档位末轮 RMS 约从 6.63 mm 减少到 5.67 mm，与下述微小侧推的 40% 降幅是不同协议。

舞台中显示当前轮次、准备 / 侧推 / 恢复阶段、实际力和横移；舞台下方显示本轮真实位移、提前补偿与基线叠加曲线，以及逐轮 RMS 曲线。暂停会冻结物理、实验时钟和学习过程。停止、取消、重置和卸载会移除实验自身施加的外力；停止时保留其他模块的外力贡献。重置物理状态、切换模型或刷新页面会清除学习记忆，目前没有磁盘持久化。

实验要求双脚支撑且身体站稳，执行期间拒绝姿态命令和关节/手指手动输入。身体降低、倾斜超限、脚部失去接触或明显滑动时取消本轮，不将该轮误差写入补偿记忆。

## 控制与学习

- `CerebellumExperiment` 仅生成实验提示和真实扰动力，不参与平衡求解。`Cerebellum` 的预测与补偿学习不读取外力数组，不以侧推时刻、力值或方向作为输入；试验时钟是显式提供的上下文。只有恢复时间统计采用所选档位的侧推结束时刻，不将此统计反馈给控制或学习。
- `Cerebellum` 以 50 ms 时间分箱记录骨盆横向位置相对双脚中心的误差。每轮完成后，将未来约 150 ms 的误差以有界学习率写入前馈参考修正，并进行相邻分箱平滑。这是迭代学习控制，学习“提示之后何时需要怎样补偿”。
- 修正限幅 ±12 mm，变化速率不超过 25 mm/s，轮次边界逐渐淡入淡出。它加到 `BalanceController` 的骨盆横向参考，现有控制器继续通过关节力矩和地面接触实现动作；不改写真实 qpos，不向根部施加辅助支撑力。足端 IK、接触约束和关节限制继续生效。
- 独立预测器约每 20 ms 更新。输入为位置误差、横向速度、当前补偿和经过限幅后的踝部侧向指令副本，预测短时间后的横向速度。实际反馈到达后，依据时间对齐的速度变化误差，用归一化在线梯度更新小型线性残差模型。
- **预测器目前用于观测和学习验证，不用于搜索最优动作。** 前馈补偿直接从跨轮次动作误差学习，尚未实现利用预测模型规划动作的控制器。

该原型依靠可重复提示进行预期性补偿，无法提前获知任意、随机时刻的侧推。侧推实验的预测器与补偿记忆只覆盖当前横向站立任务，没有全身神经控制、视觉/前庭模拟、肌肉级小脑学习或任意地形适应。

## 状态与接口

```js
window.human.setCerebellumProfile("standard"); // 可选：切回原版微小侧推；默认 visible
window.human.startCerebellumExperiment("baseline", 2); // 必须先站稳
// 上一组完成后再运行：
window.human.startCerebellumExperiment("learn", 8);
// 学习组完成后再运行：
window.human.startCerebellumExperiment("frozen", 2);
window.human.getState().locomotion.cerebellum;
window.human.getState().cerebellumExperiment;
window.human.stopCerebellumExperiment();
window.human.clearCerebellum(); // 实验运行中返回 false
```

模式为 `baseline` / `learn` / `frozen`，轮数为 1–16 的整数。启动成功返回 true，不满足站立或任务条件、输入非法时返回 false。固定基座模式不提供实验。

`cerebellum` 返回当前补偿、学习记忆峰值、预测样本数、参数更新次数、平滑速度预测绝对误差和最多 64 轮记录。记录包含：

| 字段 | 含义与单位 |
| --- | --- |
| `rms` / `peak` | 整轮骨盆横向位置误差的均方根 / 最大绝对值，m；包含扰动前的提前补偿阶段 |
| `peakTilt` | 根部相对竖直的最大倾斜角，rad |
| `work` | 人体驱动关节的绝对机械功积分，J；不是生理代谢能耗 |
| `recovery` | 侧推结束后，最后一次越过位置 0.5 mm 或速度 5 mm/s 阈值的时刻差，s；最长受 4 秒观察窗口限制 |

## 可复现实验

```bash
node --import tsx tests/cerebellum.test.ts
CHROMIUM_PATH=/opt/google/chrome/chrome npx playwright test tests/browser/cerebellum.spec.ts
```

测试加载真实 MuJoCo WASM 和自由人体模型，选择微小侧推档位，依次执行 2 轮基线、8 轮学习、2 轮冻结。默认质量模型的一次确定性运行中，基线 / 冻结平均横向 RMS 为 **0.541 / 0.324 mm**，最大偏移为 **2.620 / 1.532 mm**，降幅约 **40% / 42%**。结果仅适用于该协议，不能外推为对随机扰动的普遍提升。另一项物理测试覆盖默认明显侧推的完整学习、厘米级实测位移、轨迹记录、档位切换清理和始终站立。

逐轮 RMS、峰值、倾角、恢复时间与机械功写入 `artifacts/cerebellum/measurements.json`。测试还会撤去侧推，仅重复提示 8 轮，验证旧补偿能消退；验证冻结模式不更新参数、补偿有界、持续站立、停止时清理力、保留其他模块外力、脉冲期间重置，以及取消后不提交补偿学习。浏览器测试覆盖界面运行、暂停、停止和清除记忆。
